# 🚀 Featured Projects

## 🦾 Two-Link Planar Robotic Arm

> **SolidWorks • MATLAB • Simulink • Simscape Multibody**

A two-link planar robotic arm designed in SolidWorks, exported to MATLAB Simscape Multibody, and simulated in Simulink with inverse kinematics and PID control. A full project report is included in the repository.

### 🔹 Highlights

- Arm modelled in SolidWorks and exported to Simscape Multibody
- Desired trajectory generation
- Inverse and forward kinematics
- PID control of each joint
- Project report (PDF) included

### 🛠 Technologies

`SolidWorks` `MATLAB` `Simulink` `Simscape Multibody`

🔗 **[View Project](https://github.com/Lakshan-TECH/two-link-robotic-arm-simscape)**
